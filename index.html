How to use Roadmap Studio

          
Load a monday.com export, pick a preset, adjust the look, then export a PNG or SVG for your slides. Everything happens in this browser tab: your file is never uploaded.

Quick start

          
    
            
  1. In monday.com, open your board or Gantt view and choose Export → Export to Excel (CSV also works).
    2. 
            
  2. Click Open file… at the top, or drag the file anywhere onto this page.
    3. 
            
  3. Check the chart on the Roadmap tab. If something is missing, look at the Loaded data tab to see why.
    4. 
            
  4. Choose a preset (PowerPoint or Detailed) and fine-tune under Design.
    5. 
            
  5. Click Export PNG, Export SVG or Copy, then paste or insert it into PowerPoint.
    6. 
          


          
Loading data Data setup tab

          
The app reads the file, tries every sheet with every known export format, and keeps whichever plots the most activities. Usually you don't need to change anything here.

          

            
Open file / drop area
Loads an .xlsx, .xls, .csv or .tsv file. Loading a new file replaces the current one.

            
Try with sample data
Loads a built-in example programme so you can explore the controls.

            
File summary
Shows how many workstreams and items were plotted, how many were skipped and why, and the date span found.

            
Sheet
Only shown when the file has several sheets. Pick the one holding your board if the automatic choice is wrong.

            
Format
monday.com board / Gantt export understands group titles (which become workstreams), repeated header rows and subitem blocks. Generic table treats the sheet as one plain table with a single header row.

            
Ambiguous dates
How to read dates like 03/04/2026: UK (3 April) or US (4 March). Unambiguous dates and Excel dates are always read correctly.

            
Treat single-day items as milestones
When on, an item whose start and end are the same day is drawn as a diamond ◆. Everything longer is a bar.

            
Subitems
Auto shows subitems only where the parent has no dates of its own (the parent is then drawn as a summary bar across them). Always show draws every dated subitem under its parent as a slimmer, lighter bar. Hide leaves them out.

          


          
Column mapping

          
Tells the app which column holds what. It is filled in automatically; change a drop-down if the chart looks wrong.

          

            
Workstream
Groups the rows into swimlanes. monday.com group uses the board's group titles.

            
Activity
The item name shown on each bar or milestone.

            
Timeline
A single column holding a range such as 2026-01-06 - 2026-02-14.

            
Start date / End date
Separate start and end columns, e.g. monday.com's Timeline - Start and Timeline - End. Used when there is no Timeline value.

            
Single date
A one-date column such as Date or Due date, used when an item has no start or end. These items become milestones.

            
Milestone flag
Optional. A column containing "Milestone", "Yes" or a tick marks items as milestones whatever their dates.

            
Status
Optional. Used when Colour bars by status is on (Design → Colours).

          


          
Loaded data tab

          
Lists every row read from your file and what happened to it: Bar Milestone Summary are on the roadmap; No dates Subitem hidden Workstream hidden are not. Use the search box and the Show filter to find rows, and tick All columns to see every column from the file.


          
Presets top bar

          

            
PowerPoint
A 16:9 image (1920×1080) with the top 15% left empty for the slide title. Rows are shared where possible and the layout shrinks or grows to fit the slide. Place it as a full-slide picture and type the title in PowerPoint's title box.

            
Detailed
One activity per row, dates on every bar; the image grows taller to fit everything. Good for appendices and documents.

            
Custom
Selected automatically when you change any layout setting. Click a preset again to go back to its defaults.

          


          
Layout Design tab

          

            
Canvas
16:9 slide keeps a fixed slide shape. Auto height uses the width you set and grows as tall as needed.

            
Title space
How much of the slide's top is kept free for the PowerPoint title. The dashed guide shows it in the preview but is never exported.

            
Fit content to slide
Adjusts row height (and if needed text size) so everything fits. The note under the Layout section shows the sizes used.

            
Include a title in the image
Writes a title into the image itself, for when you're not using a slide title.

            
Font, Font size
Text style for the whole chart. Choose the font your slides use.

            
Row height, Bar thickness
Space per row, and how much of it the bar fills.

            
Workstream spacing, Margin
Gap between workstreams, and the empty border around the chart.

            
Rows
Compact lets activities share a row when they don't overlap (best for slides). One activity per row lists them like a classic Gantt.

            
Sort activities by start date
Off keeps the order from your file.

          


          
Workstreams Design tab

          

            
Heading style
A coloured band on the left with the name centred, or a centred heading row above each workstream.

            
Band width, Heading size
Size of the workstream name area and its text.

            
Tinted workstream rows
A light tint of each workstream's colour behind its rows.

            
Summary line / Group style
How a parent item and its subitems are tied together: a thin line across the parent's row spanning its subitems, plus an outline, connector lines, a side rail, a shaded band, or nothing.

            
Workstream list
Tick to show or hide a workstream, use the colour swatch to recolour it, and ▲ ▼ to reorder.

          


          
Date range & timescale Design tab

          

            
Range
Automatic fits the data (whole months, or whole weeks for short plans). Custom months lets you set the first and last month shown; items outside are left out.

            
Timescale
The column headings: weeks, months or quarters. Automatic picks one that suits the length of the plan.

          


          
Labels Design tab

          

            
Activity labels, Label position
Auto puts the name inside the bar when it fits and beside it when it doesn't. Labels outside a bar always use the dark text colour, so they never disappear.

            
Show dates
Adds start–end dates to activities, and the date to milestones.

          


          
Milestones Design tab

          

            
Placement
Inside each workstream, or gathered in a Key milestones row at the top.

            
Size, Colour
Diamond size, and one colour for all milestones or each workstream's own colour.

          


          
Today marker Design tab

          
A dashed line at today's date with a "Today" label. Use Date override to show a different date, such as a reporting date.


          
Colours Design tab

          

            
Palette
Workstream colours. Individual workstreams can be recoloured in the Workstreams list.

            
Colour bars by status
Colours bars by the mapped Status column (done, in progress, stuck, not started) and adds a legend.

            
Background, Text, Secondary text, Gridlines
Page colours. If a text colour would be unreadable on the background, the app picks a readable one.

          


          
Exporting top bar

          

            
Scale
PNG size multiplier: 3× turns a 1920×1080 slide into 5760×3240 pixels, sharp on any projector.

            
Export PNG
Downloads a picture file. The dashed title guide is not included.

            
Export SVG
Downloads a vector file that stays sharp at any size. Recent PowerPoint versions can insert it and even convert it to editable shapes.

            
Copy
Copies the PNG to the clipboard so you can paste it straight into PowerPoint.

          


          
Troubleshooting

          

            
"Nothing could be plotted"
Open the Loaded data tab to see each row's status. Most often the dates are in a column that isn't mapped (fix under Column mapping), or the dates are only on subitems (set Subitems to Always show). Copy these details gives a summary you can share, with no item names.

            
An item is missing
Find it in Loaded data: it may have no dates, be a hidden subitem, sit in a hidden workstream, or fall outside a custom date range.

            
Dates are a month out
Switch Ambiguous dates between UK and US.

            
The slide is too crowded
Hide some workstreams, use compact rows, show milestones in the Key milestones row, or switch to the Detailed preset for an appendix.

          


          
Privacy

          
Your file is read inside this browser tab and is never uploaded. The page blocks all network requests. Only layout and colour preferences are remembered in this browser; nothing from your file is stored.
